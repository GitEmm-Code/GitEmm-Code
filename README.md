## About me

I'm emm, a web designer and developer based in Mexico City. I run **[Stud!o](https://getstudio.mx)**, a web design and development studio.

- 🌐 I design and build websites and online stores, then keep them running with hosting and support
- ✨ I care about motion, depth and the details people remember
- 🔤 Lately I've been turning birds and waves into animated ASCII art
- 🇲🇽 I build in Spanish and English
